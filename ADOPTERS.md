# Adopters

This page lists organizations and projects using `wimsey`, whether in
production, for evaluation, or as prior art for their own WIMSE work.

`wimsey` is pre-alpha and implements unfinished IETF Internet-Drafts, so there
are no production adopters yet. If you are using it — even to experiment or to
validate another implementation against its conformance vectors — please add
yourself by opening a pull request that appends a row to the table below.
